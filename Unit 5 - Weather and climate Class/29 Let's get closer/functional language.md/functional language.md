# Unit 5 Functional Language

## Class 29: Let's Get Closer

### Class Profile

| Functional Language | Can-do Statement |
| --- | --- |
| Talking about preferences, adding emphasis, giving examples | Talk about my preferences, add emphasis, and give examples. |

| Talking About Preferences | Adding Emphasis | Giving Examples |
| --- | --- | --- |
| I would sooner ... | I absolutely love the idea of ... | For instance, ... |
| I would rather ... | What I really love is... | To give an example, ... |
| I would prefer ... | It's something I'm really into... | If I can use an example, ... |
| I would just as soon ... | I have a special preference for... | I'd like to illustrate my point with an example ... |
