# Unit 9 Functional Language

## Class 53: The Upside and the Downside

### Class Profile

| Functional language | Can-do Statement |
| --- | --- |
| Discussing pros and cons, contrasting, saying your opinion | Talk about advantages and disadvantages, use contrasting phrases, and express your opinion. |

### Sort Out the Phrases

Sort out the phrases into two categories.

| Discussing Pros | Discussing Cons |
| --- | --- |
| An argument for this is... | One disadvantage is... |
| One advantage is... | An objection to... |
| It offers several benefits, such as... | An argument against this is... |
| A positive aspect... | It's a con that... |
| An upside to this is... | A downside to this is... |
| It's a plus that... | It offers several drawbacks, such as... |

### Contrasting

| Phrase Pair |
| --- |
| Initially... / Conversely... |
| While... / However... |
| Whereas... / Nonetheless... |
| In comparison... / On the contrary... |
| On the one hand... / On the other hand... |
| On one side of the coin... / On the flip side... |

### Saying Your Opinion

| Phrase |
| --- |
| From my perspective, ... |
| From where I stand, ... |
| I'm inclined to think that ... |
| I feel that ... |
| In my view... |
| It seems to me that ... |
