# Unit 8 Functional Language

## Class 47: What About Hosting the Olympics?

| Topic | Can-do Statement |
| --- | --- |
| Vague language and generalising | Use vague language, make things sound less factual, and speak in general. |

| Generalising | Vague Language |
| --- | --- |
| In most cases | more or less |
| More often than not | about / around |
| Mostly | and that kind of thing |
| On the whole | kind of / sort of |
| Generally speaking | and stuff like that |
| Generally | or something like that |
| As a rule | and so forth |
