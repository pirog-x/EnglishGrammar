# Unit 6 Functional Language

## Class 35: What Should I Do?

### Class Profile

| Functional Language | Can-do Statement |
| --- | --- |
| Asking for and giving advice | Ask for advice, suggest, and recommend something. |

| Asking for Advice | Giving Advice |
| --- | --- |
| What can I do? | If I were you, I'd... |
| What can you suggest? | You had better / ought to... |
| Any thoughts on this? | My advice would be... |
| What should I do? | I think you should... |
| Have you got any ideas? | How / what about ...? |
| What would you do? | Why don't you ...? |
