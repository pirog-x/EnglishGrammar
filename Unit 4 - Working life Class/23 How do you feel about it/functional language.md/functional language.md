# Unit 4 Functional Language

## Class 23: How Do You Feel About It?

### Class Profile

| Functional Language | Can-do Statement |
| --- | --- |
| Asking for and giving opinion, agreeing and disagreeing, opinion adjectives | Ask for opinions and express my point of view using opinion adjectives and phrases for agreeing and disagreeing. |

| Giving Opinion | Asking for Opinion |
| --- | --- |
| I'm convinced that... | How do you see...? |
| It seems to me that... | How do you feel about...? |
| From my perspective, ... | What's your take on...? |
| Basically / Personally, I believe / think / feel ... | What are your views on...? |
